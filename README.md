# Irish Electricity Demand Forecasting — Hybrid LSTM-XGBoost

MSc Data Analytics research project. Hybrid LSTM-XGBoost model for
event-driven, half-hourly electricity demand forecasting in Ireland,
with a focus on major Dublin events.

## Run order
1. Merging_the_Dataset.ipynb
2. EDA.ipynb
3. Public_holidays.ipynb
4. Step3_Baseline_XGBoost.ipynb
5. Step3b_Additional_Models.ipynb
6. Step4_LSTM.ipynb
7. Step5_Hybrid_LSTM_XGBoost.ipynb
8. Step5b_Hybrid_GRU_XGBoost.ipynb
9. Step6_SHAP_Analysis.ipynb
